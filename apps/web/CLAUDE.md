# Web Package Map

`app/` owns routes, `components/` owns visual building blocks, `src/domain/` owns pure transitions, `src/server/` owns authenticated infrastructure, `src/webmcp/` owns the experimental browser adapter, and `src/demo/` owns disposable fixtures.

`src/domain/jarvis-review.ts` is the deterministic readiness critic shared by the demo and persistent investigation UI. `components/jarvis-advisor.tsx` renders its ranked next action. Active investigations expose seven tools; approved history exposes three read-only tools. No JARVIS path may bypass researcher confirmation or initiate a decision-brief download.
