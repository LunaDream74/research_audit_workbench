# Repository Agent Contract

- Follow `docs/hackathon-build/checklist.md` in order and do not begin P1 before P0 passes end to end.
- `apps/web` is the only durable-write owner. `apps/api` is stateless and must never receive database credentials.
- Facts and citations come from deterministic code. Agent prose is a proposal, never evidence.
- WebMCP tools may inspect context or stage reversible previews; they may not confirm imports, create findings, save challenges, approve plans, delete data, or execute experiments.
- Active investigations expose seven tools; approved history exposes only the three applicable read-only tools.
- Run the verification named by the active checklist item before marking it complete.
